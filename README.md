# SSH Educational Website

A multi-page educational website built using *HTML5* and *CSS3*, showcasing clean UI design, structured navigation, and static content related to school activities such as assignments, homework, exams, and services.

This project demonstrates strong fundamentals in front-end development, web structure, layout design, and responsive styling.

---

## 🚀 Features

### 🌐 Multi-Page Website
Includes multiple structured pages:
- *Home (Index)*
- *About Us*
- *Homework*
- *Assignments*
- *Online Exams*
- *Services*
- *Contact Us*

### 🎨 Clean UI / UX
- Organized layout  
- Easy navigation  
- Consistent color palette  
- Readable typography  

### 🧩 Front-End Fundamentals
- Semantic *HTML5*
- Modular and organized *CSS*
- Reusable components (headers, footers, navbars)
